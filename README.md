# Workout Routine Manager
Приложение за следене на фитнес развитието Ви, създадено по време на стажантска програма в Scalefocus.

## Функции
### 1.Регистрация и логин
-  Регистрация с имейл и парола
-  Вход с имейл и парола
-  Вход/регистрация чрез Google OAuth
-  Забравена парола → изпращане на имейл с линк за нова
  
 ### 2.Управление на потребител
- Промяна на парола
  
### 3.Създаване на рутина
-  Добавяне на нова рутина (име, sets, reps, rest, weight)
-  Изтриване на рутина
-  Преглед на всички рутини
  
### 4.Календар
-  Добавяне на тренировка в календара
-  Синхронизация с Google Calendar
  
### 5.Проследяване на развитие
-  Страница с графики, които визуализират прогреса ви във времето
  
## Технологии
- React
- Supabase 
- Material-UI
- Formik
